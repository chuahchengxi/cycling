# Bundle LTA parking, curate rental shops by hand

The best bicycle-parking source to bundle offline as of 20 Nov 2026 is **LTA DataMall's Bicycle Parking API v3**. It launched on **30 Oct 2026**, refreshes **monthly**, and adds `SharedBicycleParking` and `Type` fields that let an app tell tourists where a shared-bike trip can legally end. It falls under the **Singapore Open Data Licence**, which allows commercial redistribution with a conspicuous attribution notice. Every other parking source is weaker. The only downloadable government file, data.gov.sg's "LTA Bicycle Rack (GEOJSON)", holds **396 points and 19,329 lots, all stamped 3 Jul 2019**, against a national stock officially put at 246,000 to 280,000 lots. OpenStreetMap has at most **972 parking and 207 rental objects across Malaysia, Singapore and Brunei combined**, and it carries ODbL share-alike terms. No open dataset of rental shops exists. GoCycling is the only operator whose outlets could be confirmed on its own live site, and only eight of its claimed eleven are listed there. Everything else comes from blogs dated 2017 to 2026, some of which contradict each other. The rules a tourist most needs are simple and strict. Shared bikes (only **Anywheel** and **HelloRide** remain) must be ended at an LTA QR-coded rack or yellow box, or the rider pays a **$5 fee** and can be banned after repeat offences. Shared bikes are **banned on Pulau Ubin**. Most GoCycling kiosks are return-to-same-place. So the app should ship the LTA layer as fact, ship a small hand-curated rental list with "last verified" dates, and ship the rules as text.

## LTA's three-week-old v3 API is the only fresh, complete parking feed

The v3 endpoint is `https://datamall2.mytransport.sg/ltaodataservice/v3/BicycleParking`. It takes mandatory `Lat` and `Long` and an optional `Dist` radius in km (default 0.5). The guide documents **no maximum `Dist`**. Each record returns `Description` (e.g. "Bus Stop 43267"), `Latitude`, `Longitude`, `RackType` ("Racks or Yellow Box"), `RackCount`, `ShelterIndicator`, and the two new fields `SharedBicycleParking` ("Yes") and `Type` ("RACK") ([LTA DataMall API User Guide v6.11](https://datamall.lta.gov.sg/content/dam/datamall/datasets/LTA_DataMall_API_User_Guide.pdf)). Requests need an `AccountKey` header. Responses are capped at **500 records per call** and paged with `$skip`, and Bicycle Parking is not among the exceptions to that cap. The terms allow up to **10 million calls a day**, require credentials to be kept confidential, and let LTA end access "for any reason whatsoever" ([LTA API Terms of Service](https://datamall.lta.gov.sg/content/datamall/en/api-terms-of-service.html)). DataMall's Geospatial Whole Island download has 34 layers, including `CyclingPath` and `CoveredLinkWay`, but **no bicycle-parking layer**. The point-and-radius API is therefore the only way to get the full set.

The data.gov.sg file is easy to fetch with no key. A `poll-download` call to dataset `d_937424cca6d1617288a82a7aeb89f76d` returns a pre-signed link that expires in an hour. Its contents, though, are a KML export frozen in time. Each feature has only `Name` ("kml_1") and an HTML-table `Description` holding `SHLTR_IND`, `TYP_CD` (Single 274, Double 85, Yellow-box 37), `RACK_CNT` and `FMEL_UPD_D`. Every update stamp is **3 Jul 2019**, so the listing's "last updated 06 Jun 2024" reflects a metadata republish, not new data ([data.gov.sg](https://data.gov.sg/datasets/d_937424cca6d1617288a82a7aeb89f76d/view)). Its 19,329 lots are under a tenth of the island's stock. An MOT reply gives **over 246,000** public lots ([MOT](https://www.mot.gov.sg/news-resources/newsroom/oral-reply-by-senior-parliamentary-secretary-for-transport-baey-yam-keng-to-parliamentary-question-on-meeting-demand-for-bicycle-parking-lots/)), and LTA figures cited on Wikipedia give about **280,000** ([Wikipedia](https://en.wikipedia.org/wiki/Cycling_in_Singapore)). Neither figure's date is confirmed. No separate URA, NParks or HDB rack dataset turned up. HDB racks, which are provided at one lot per six flats, may or may not be inside the DataMall feed ([WP written answers, 6 Mar 2026](https://www.wp.sg/parliament/written-answers-to-wps-oral-questions-and-written-questions-on-06-mar-2026)).

| Source | Licence | Key fields | Freshness | Main gap |
|---|---|---|---|---|
| DataMall Bicycle Parking v3 | Singapore Open Data Licence | Description, lat/lon, RackType, RackCount, ShelterIndicator, SharedBicycleParking, Type | Monthly; v3 since 30 Oct 2026 | Needs key; radius queries only; total count and enum values unknown |
| data.gov.sg LTA Bicycle Rack GeoJSON | Singapore Open Data Licence | Name, HTML Description (shelter, type, count) | All records 3 Jul 2019 | 396 points, about 8% of lots |
| OSM `amenity=bicycle_parking` / `bicycle_rental` | ODbL | capacity, covered, operator, ref (unevenly filled) | Daily diffs | 972 / 207 objects for 3 countries; no import of LTA data |
| GoCycling website | Not open data (facts only) | Address, postcode, hours, outlet type | Live, Nov 2026 | Text lists 8 of 11 outlets; map is an image |
| Blogs (TheSmartLocal, TheMoneyBees, Little Day Out) | Copyrighted editorial | Address, hours, price | Nov 2025 to Oct 2026, some 2017 to 2021 | Conflicting open/closed status |

Two points remain unverified because no API key was available during the research. One is whether `SharedBicycleParking = Yes` matches the set of racks that actually carry LTA QR codes. The other is whether older v1 and v2 endpoints still respond. Both should be checked on the first build-time pull.

## Shared-bike rules turn the parking layer into a tourist safety feature

Bike sharing is now a duopoly. SG Bike left in **April 2024** ([SUTD](https://sutd.edu.sg/About/happenings/News/2024/7/No-longer-eyesore-are-shared-bikes-viable-option)). Anywheel runs about **35,000** bikes and HelloRide reports **25,000** after a 2026 approval ([HelloRide](https://www.helloride-global.com/helloride-grows-to-25000-bicycles-across-singapore/); [Wikipedia](https://en.wikipedia.org/wiki/Cycling_in_Singapore)). HelloRide's previous 20,000-bike licence ran to 30 Jun 2026 ([People's Daily](https://en.people.cn/n3/2025/0702/c90000-20335079.html)). No 2026 LTA renewal notice was found, so current expiry dates for both operators are unknown.

Since **14 Jan 2019**, a shared-bike trip can only end after the rider scans an LTA QR code at a designated rack or yellow box ([LTA](https://lta.gov.sg/content/ltagov/en/newsroom/2018/12/2/qr-code-parking-system-for-bicycle-sharing-to-take-effect-on-14-january-2019.html)). Improper parking costs **$5**, and repeat offenders are banned ([MOT, 27 Feb 2026](https://www.mot.gov.sg/news-resources/newsroom/holding-bicycle-sharing-operators-accountable-for-bicycles-parked-outside-designated-zones-/)). Enforcement is rising. Penalty fees went from about **90,000 in all of 2025 to about 148,000 in Jan to Jul 2026**, and about 4,800 users were banned in each period, even though about 95% of trips end correctly ([MOT, 8 Sep 2026](https://www.mot.gov.sg/news-resources/newsroom/complaints-and-fines-related-to-shared-bicycles-parked-outside-designated-zones/)). The original rule banned anyone with three offences in a calendar year from all operators for a month, with bans of up to a year for repeat offenders. Whether those thresholds still apply in 2026 is unconfirmed ([Land Transport Guru](https://landtransportguru.net/bike-sharing-in-singapore/)). The QR codes themselves are not public. An OSM mapper who hand-surveys them in Hougang and Sengkang notes that "neither the parking spots nor the associated QR-codes are available for download" ([OSM diary](https://www.openstreetmap.org/user/ADsdfjk23/diary/401848)). Anywheel also runs private bays, for example at Hotel JEN and Mandai Wildlife Reserve, that only its own app recognises, and these appear in no open dataset ([Wikipedia](https://en.wikipedia.org/wiki/Cycling_in_Singapore)). The operator's app therefore remains the final authority on where a trip ends. An offline layer can only show where it probably can.

Getting started is cheap but not well documented for visitors. Anywheel charges **S$1 per 30 minutes** and sells passes of **S$6.90 (7 days), S$9.90 (30 days) and S$26.90 (90 days)**, with no deposit but a minimum wallet balance ([Trip.com](https://sg.trip.com/guide/phone/anywheel-singapore.html)). A 2025 guide gives lower pass prices ([SingSaver](https://www.singsaver.com.sg/blog/bicycle-rental-singapore)), so prices should not be hard-coded. HelloRide charges about S$1 for the first 30 minutes, then about S$0.50 per 10 minutes ([Trip.com](https://sg.trip.com/guide/phone/helloride-singapore.html)). A partly China-focused guide says HelloRide accepts **international phone numbers** and Visa, Mastercard, Apple Pay or Google Pay ([Trip.com](https://sg.trip.com/guide/transport/helloride.html)). Foreign-number support for Anywheel is not stated anywhere.

The riding rules that catch tourists come from LTA and NParks. Helmets are compulsory **on roads only**. Bikes are banned on expressways, road tunnels and some viaducts. Riders must dismount at "No Riding" signs and use front and rear lights at night ([LTA](https://www.lta.gov.sg/content/ltagov/en/getting_around/active_mobility/rules_and_public_education/rules_and_code_of_conduct.html)). Since **1 Jul 2025**, riding on pedestrian-only paths beside cycling paths carries a fine of up to **$2,000**, up to 3 months' jail, or both ([LTA](https://www.lta.gov.sg/content/ltagov/en/newsroom/2025/7/news-releases/pedestrian-only_paths_enforcement_starts_1Jul25.html)). Sixty enforcement cameras target speeding ([LTA, Aug 2026](https://www.lta.gov.sg/content/ltagov/en/newsroom/2026/8/news-releases/enforcement-operations-enhanced-active-mobility-regulations.html)). Shared bikes and PMDs **may not be taken onto Pulau Ubin**, so visitors must rent from the island's shops ([NParks, 16 Jun 2026](https://pulau-ubin.nparks.gov.sg/notice-for-usage-of-bicycles-personal-mobility-devices-and-motorised-vehicles/)). The footpath speed limit is disputed: a 2026 secondary guide says 10 km/h, while the 2018 rule was 15 km/h ([Wikipedia](https://en.wikipedia.org/wiki/Cycling_in_Singapore)). The app should not state a footpath figure until LTA's "Where You Can Ride" PDF is checked. Sentosa's rules for shared bikes were not found.

## Only GoCycling's five full-service outlets support one-way rentals

GoCycling's site publishes network-wide terms. Adults pay from **$10/hr**, kids $8/hr, tandems $20/hr and family bikes $40/hr. There is a **$50 cash deposit**. Last rental and latest return are **30 minutes before closing**. Bikes can be returned to **any full-service outlet**, but **self-service kiosks are standalone and need a same-kiosk return**. Night rental costs $20 plus a compulsory $2 lock. Helmets and e-bikes are not mentioned ([GoCycling](https://www.gocycling.sg/)). The site claims "11 outlets islandwide" but its text names only eight:

The three unlisted outlets are probably Marina Bay (Singapore Flyer, S039803), Punggol Jetty (S829170) and Jurong Lake Gardens (S600353). A November 2025 guide lists them along with Punggol Park ([TheSmartLocal](https://thesmartlocal.com/read/bicycle-rental-singapore/)), but GoCycling's own outlet map is an image, so this could not be confirmed. The full-service set makes a tourist-friendly one-way ride possible, for example from Changi Airport T2 to ECP C4, as long as the destination has space. That is the main reason to model GoCycling outlets as a typed graph and not as plain pins.

Independent shops are where the data gets messy. **Coastline Leisure / Bike Stop at ECP B1 and E2** still appears with hours in guides from November 2025 and October 2026 ([TheMoneyBees](https://themoneybees.co/blog/bicycle-rental-singapore); [TheSmartLocal](https://thesmartlocal.com/read/bicycle-rental-singapore/)). A 2026 search summary of Little Day Out, however, says both are "believed to be no longer available", with only the Marine Parade Central outlet remaining ([Little Day Out](https://www.littledayout.com/east-coast-park-bicycle-rental/)). Hours conflict too: GoCycling lists ECP G1 as 10am–7pm, while TheSmartLocal says 8am–10pm. Other shops have a single blog source: City Scoot at Esplanade, The Bicycle Hut at High Street Centre, Momentum at Pasir Ris, and Jomando, Bike Stop @ Waterway and WHEEELERS in Punggol ([TheSmartLocal](https://thesmartlocal.com/read/bicycle-rental-singapore/)). Pasir Ris café rentals rest on a 2017 guide ([Little Day Out](https://www.littledayout.com/pasir-ris-bike-rental-guide/)). On **Pulau Ubin**, shops cluster at the jetty and rent by the day, from **S$15.50 per day** at No. 25 (Nov 2025), with no postcodes ([TheSmartLocal](https://thesmartlocal.com/read/bicycle-rental-singapore/)). On **Sentosa**, GoGreen at 51 Siloso Beach Walk rents in 1- and 2-hour slots, with hours given as 10am–6:15pm on one booking site and 10am–7:30pm on another, and no official Sentosa page ([Headout](https://www.headout.com/singapore-bike-tours/go-green-bi-pedal-bicycle-rental-in-sentosa-e-7409); [Traveloka](https://traveloka.com/en-sg/activities/singapore/product/gogreen-segway-eco-adventure-4536940205280)).

Gaps in coverage matter as much as the shops. Cycling is generally not allowed inside Gardens by the Bay. Riders park at Bay South and walk, and the nearest staffed rental is at the Singapore Flyer ([Little Steps Asia](https://www.littlestepsasia.com/singapore/play/outdoor-activities/cycling-gardens-by-the-bay-singapore/)). No rental was found at the Southern Ridges, Bishan-AMK Park, the Rail Corridor, Mandai or the Botanic Gardens, so riders there must use shared bikes. Guided tours are sold through travel booking sites, for example Let's Go Bike on Go City, Lion City Bike Tour from USD 67 on Pelago, and Ubin half-days of about S$95 ([Go City](https://gocity.com/singapore/en-us/attractions/lets-go-bike-singapore); [Pelago](https://www.pelago.com/en-US/activity/p1ckw-lion-city-bike-tour-singapore/); [Asian Trails](https://www.asiantrails.travel/trail/half-day-ubin-bike-trail/)). None was confirmed as licensed by the Singapore Tourism Board, and tours are booking products, not places to pick up a bike.

## OpenStreetMap adds licence cost without adding coverage

Geofabrik's taginfo, with data to 19 Nov 2026, counts **972 `amenity=bicycle_parking`** objects (841 nodes, 129 ways, 2 relations) and **207 `amenity=bicycle_rental`** objects for Malaysia, Singapore and Brunei together ([taginfo parking](https://taginfo.geofabrik.de/asia:malaysia-singapore-brunei/api/4/tag/stats?key=amenity&value=bicycle_parking); [taginfo rental](https://taginfo.geofabrik.de/asia:malaysia-singapore-brunei/api/4/tag/stats?key=amenity&value=bicycle_rental)). The Singapore-only count is lower, but the Overpass query for it failed. Even the three-country total is far below LTA's lot stock. Singapore mappers tag QR drop-off points as `amenity=bicycle_rental` + `bicycle_rental=dropoff_point` with `network=LTA QR Code Parking System`, but only in parts of Hougang and Sengkang ([OSM diary](https://www.openstreetmap.org/user/ADsdfjk23/diary/401848)). No import of LTA bicycle parking into OSM exists. A 2022 covered-linkway import shows LTA will grant permission for one ([OSM imports list](https://lists.openstreetmap.org/pipermail/imports/2022-September/006953.html)). Bundling OSM data brings ODbL obligations: attribution to "© OpenStreetMap contributors" and share-alike on any merged database that is distributed publicly. That summary of the licence was not checked against the licence text during this research. In practice, OSM's only distinct value here is private mall and condo racks, and the research could not measure how many of those exist.

## Conclusion

Bike parking in Singapore looks like a data problem, but the data is settled: LTA's v3 feed is fresh, open and redistributable, and its new shared-parking flag arrived just in time. The unsolved problem is rentals. No authority publishes shop locations, the largest chain publishes only part of its network, and blogs disagree about which shops still exist. An app should treat rental shops as editorial content with an owner and a re-verification schedule, not as a dataset to sync. The highest-value tourist feature is not a map of shops. It is a warning at the right moment: "this spot may not end your Anywheel trip", "this kiosk needs a same-place return", "you cannot take this bike to Ubin". Each warning prevents a fee or a stranded rider, and each can be derived offline from the sources above.

## Recommended bundle for the app

**Ship the DataMall v3 Bicycle Parking layer as the primary dataset.** Pull it at build time in CI, never from the client, with the `AccountKey` read from a CI secret. Tile the island (about 50 × 27 km) with points about 2 km apart and `Dist=1.5`, which comes to roughly 300–400 calls. Page each point with `$skip` until a page returns fewer than 500 records. Dedupe on (Latitude, Longitude, Description) and write compact GeoJSON or SQLite that keeps all eight fields. Fail the build if the record count drops sharply from the last pull. Re-run monthly to match LTA's refresh. Record the pull date in the bundle so the attribution and the app's "data as of" label use it. On the first pull, log the distinct values of `RackType` and `Type` and turn them into app enums. Use `SharedBicycleParking = Yes` (or `RackType` = yellow box) to show a "shared-bike trip can end here (probably)" badge, worded as advisory.

**Ship a hand-curated rentals JSON.** Include GoCycling's eight site-confirmed outlets with `outletType` (full-service / self-service), `returnPolicy` (any full-service / same kiosk), hours, the closing-time-minus-30-minutes rule and `lastVerified: 2026-11-20`. Add the three probable GoCycling outlets, the Pulau Ubin jetty shops (as a single cluster, "rent here; shared bikes banned on the island") and GoGreen Sentosa with an `unverified` badge. Add GoCycling coordinates by geocoding the published postcodes with OneMap at build time. Leave out prices, or show them as "from $X/hr, check on site", because they drift.

**Ship rules as static text**, each with a source link and date: the QR end-trip rule and $5 fee, the Pulau Ubin shared-bike ban, helmets on roads, pedestrian-only path fines, the expressway and tunnel ban, the Gardens by the Bay dismount rule, the 30-minute billing blocks, and the GoCycling deposit and return rules.

**Attribution text** for the about screen, and next to the parking layer: "Contains information from Bicycle Parking accessed on {pull date} from LTA DataMall which is made available under the terms of the Singapore Open Data Licence version 1.0 https://data.gov.sg/open-data-licence". Do not imply LTA endorsement ([Singapore Open Data Licence](https://data.gov.sg/open-data-licence)). If any OSM layer is shipped, add "© OpenStreetMap contributors, ODbL" with a link to openstreetmap.org/copyright, and keep it as a separate file that is never merged with LTA data. Operator names (GoCycling, Anywheel, HelloRide) are used only as factual labels, with no logos.

**Leave out** the data.gov.sg 2019 rack GeoJSON, which v3 supersedes (keep it only as a test fixture or an emergency fallback if a key is ever revoked). Leave out OSM parking, which adds share-alike duties for marginal coverage. Leave out operator in-app zones and Anywheel private bays, which are unpublished. Leave out blog-only shops whose status conflicts (Coastline ECP B1/E2) or whose sources are pre-2024 (Pasir Ris cafés, the 2021 Ubin list beyond the jetty cluster). Leave out guided tours, live bike availability, and any footpath speed-limit number until LTA's PDF confirms it.
